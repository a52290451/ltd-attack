# LTD-Attack — migration plan

This plan is the approval point for the physical reorganization. It is intentionally limited to path changes and directory markers; source contents, historical experiments, imports, and data are not refactored.

## Invariants

- Every tracked source or documentation file is moved with `git mv`.
- No tracked file is deleted or duplicated.
- Large local datasets and all external/Zeus artifacts stay at their current paths.
- Local figures and other result files stay in place until the Zeus reconciliation.
- Duplicate historical files keep separate provenance subdirectories under `legacy/`.
- `docs/migration/LOCAL_MIGRATION.csv` records every move and every retained local data/artifact path.

## Deliberately retained in place

`01_all_features.csv`, `final_vectors_sites.csv`, `05_01_daily_embeddings_maestras.csv`, `06_all_site_embeddings_maestras.csv`, `site_dictionary.csv`, and all tracked PNG figures remain at their current paths. They are recorded with `action=retain-local-artifact` in the migration manifest. External checkpoints and result paths referenced by scripts are not local files and are not moved.

## Execution order

1. Create the target directory skeleton and this plan.
2. Execute the approved path changes using `git mv`, in the batches above.
3. Write the final migration CSV and repository structure document.
4. Search moved files for stale relative paths/imports without refactoring them.
5. Verify Git has no deleted files, then report `git status` and `git diff --stat`.

## Phase 2 plan — local root cleanup

This second plan is prepared before the filesystem moves.

| Batch | Source | Destination | Action | Reason |
|---|---|---|---|---|
| Local datasets | The five tracked root CSVs | `data/local/historical/` | `git mv` | Remove datasets from the root while preserving their tracked history. |
| Historical diagnostic figures | All tracked PNGs in `Graficas/` | `results/historical/diagnostics/Graficas/` | `git mv` | Keep figure context and distinguish results from source code. |
| Historical Macro figures | All tracked PNGs in `features_old/` | `results/historical/macro/features_old/` | `git mv` | Preserve the old feature-generation provenance. |
| Historical DML figures | All tracked PNGs in `deep_metric_learning/` | `results/historical/dml/deep_metric_learning/` | `git mv` | Preserve the phased DML provenance. |
| Local bytecode | Four untracked `.pyc` files in old directories | `legacy/diagnostics/bytecode/<origin>/` | `mv` | Retain local files without leaving generated bytecode in obsolete directories. |
| Root filesystem metadata | Root `.DS_Store` | `legacy/diagnostics/metadata/.DS_Store` | `mv` | Keep the file without leaving non-project metadata at root. |
| Credential file | Ignored, untracked `credentials_qwen.json` | `../credentials_qwen.json` | `mv` | Remove the secret from the repository root without reading or destroying it. |
| Empty directories | The ten listed historical directories after content moves | no replacement | `rmdir` | Remove only directories demonstrated empty after migration. |

No Zeus checkpoint or external result path is part of this phase. `docs/.DS_Store` remains inside the already allowed `docs/` tree as ignored metadata; no secret content is inspected.
