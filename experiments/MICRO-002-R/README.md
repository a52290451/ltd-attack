# MICRO-002-R

Controlled reproduction of historical experiment MICRO-002.

Purpose:
verify that the historical MICRO-002 result can be reproduced using
the preserved code, datasets and configuration.

Expected historical result:

- IID historical accuracy: approximately 96.45%
- Future Concept Drift accuracy: approximately 23.21%

This experiment does not define the methodology for new experiments.

If reproduced successfully, MICRO-002 can move from R3 to R4.

New experiments after this reproduction must use temporal splits.
