# LTD-Attack — Technical Scientific English Protocol (v1)

**Genre:** peer-reviewed network security / privacy / encrypted traffic analysis / ML evaluation; formal American English; third-person scholarly voice. This is a project editorial protocol (not an installed third-party proofreader).

## Required review passes
1. **Terminology fidelity:** use *website fingerprinting (WF)*, *closed-world*, *packet-direction trace*, *temporal distribution shift*, *concept drift* only when substantiated, *longitudinal profile*, *micro/macro/hybrid branches*, *paired date-block bootstrap*, *mean reciprocal rank (MRR)*. Distinguish inter-packet timing (within visit) from longitudinal time (between visits).
2. **Evidence fidelity:** every numerical claim must trace to one frozen run manifest, supplied console, or repository evidence; never fabricate missing NetCLR/ablation/Dataset C data; distinguish inference from descriptive comparisons.
3. **Inference discipline:** report pp for accuracy differences, specify whether uncertainty is percentile-bootstrap or another construction; do not call retrospective S6 Holm8 a final family-wise corrected analysis for S7-S9.
4. **Threat-model precision:** name the observer and available features; clarify whether macro descriptors are available at inference without privileged labels/future information.
5. **Tense and voice:** present tense for method and established literature; past tense for executed experiments; future/planned only for clearly marked future work. Avoid promotional wording: *novel*, *state of the art*, *robust*, *significant*, *proves*, *guarantees* without direct evidence.
6. **Sentence engineering:** one central claim per sentence; define all acronyms on first use; consistent decimal precision and samples/classes/date units; avoid unexplained two-month/60-day claims inherited from outdated preliminary text.
7. **Citation audit:** verify original paper metadata and DOI independently; add Tik-Tok, VarCNN, CUMUL and NetCLR archival references before submission; cite implementations separately from original methods.
8. **Reviewer challenge:** independently check leakage, label availability, hyperparameter decisions, code-to-paper correspondence, fairness, compute budget, and external validation status.

## Submission quality gate
- No unsupported quantities; all tables regenerated from immutable manifests (current table is human-verified transcribed draft).
- All hypotheses, uncertainty methods, and families fixed/labelled before final statistical reporting.
- Compiles with zero undefined citations and cross-references.
- Architecture diagram mirrors frozen code, not preliminary workshop art.
- Final prose revised by a domain specialist and paper authors before submission.
